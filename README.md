#### Featured projects

- **[freelance-engine](https://github.com/Kikobazz123/freelance-engine)**: a daily
  pipeline that finds contract work, scores it and drafts tailored applications.
  TypeScript, Inngest on Vercel, Neon Postgres, Gmail and Telegram APIs, LLM failover.
  *The model produces, deterministic code decides: every draft passes a claim
  validator before it can send, and a test enforces that no code path posts to a
  marketplace.*
- **[lordgen-brightpath-dashboard](https://github.com/Kikobazz123/lordgen-brightpath-dashboard)**:
  an AI sales assistant that captures, analyses, scores and follows up leads.
  Next.js 16, React 19, Drizzle, Neon, Zod.
  *The LLM only extracts evidence, each item quoted from the source; a pure,
  versioned rubric computes the score, so identical evidence always scores the same.*
- **[learn-expense-tracker-api](https://github.com/Kikobazz123/learn-expense-tracker-api)**:
  a REST API with JWT auth, per-user expenses, filtering, pagination and summaries.
  FastAPI, SQLAlchemy, pytest, GitHub Actions.
  *Each test runs on its own temporary database, and writing the suite surfaced
  three real bugs, including a password hash leaking from `/me`.*
- **[content-avatar-pipeline](https://github.com/Kikobazz123/content-avatar-pipeline)**:
  turns a script and two recordings into a captioned vertical short, then stages
  posts per platform. Python, ffmpeg, faster-whisper, Remotion.
  *Captions align the script to real word timings and refuse to render when too
  little of it matches; nothing publishes without a human.*

Also: [learn-voting-system](https://github.com/Kikobazz123/learn-voting-system), a
phased election contract in Solidity with Hardhat.
